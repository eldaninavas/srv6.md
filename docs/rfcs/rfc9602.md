# RFC 9602 - SRv6 Segment Identifiers in the IPv6 Addressing Architecture

| Field | Value |
|-------|-------|
| **Title** | Segment Routing over IPv6 (SRv6) Segment Identifiers in the IPv6 Addressing Architecture |
| **Date** | October 2024 |
| **Status** | Proposed Standard |
| **Link** | [datatracker.ietf.org/doc/rfc9602](https://datatracker.ietf.org/doc/rfc9602/) |

## Summary

RFC 9602 reserves `5f00::/16` from the IPv6 address space for SRv6 Segment Identifiers (SIDs), so SIDs can be recognized and filtered easily within an SR domain. The block is forwardable but not globally reachable. Operators may still use their own GUA prefixes as locators.

See [SID Structure](../topics/sid-structure.md#iana-allocated-srv6-sid-block-5f00-16) for the registry properties, allocation hierarchy, and boundary filtering examples.
