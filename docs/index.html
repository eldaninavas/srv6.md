    SRv6 Documentation¶

    The index of SRv6 documentation: the SRv6.md learning path, plus the official SRv6 configuration guides and reference docs of every vendor and open-source project. Each link goes straight to the SRv6 chapter, not to a generic landing page. Every link was checked on 22 October 2026, against the latest release we could find.

    Looking for one place to learn SRv6?

    Start with What is SRv6?, then follow the SRv6 fundamentals learning path. For design and migration decisions, read the free SRv6 White Paper 2026. Every other public white paper is in the SRv6 white paper library.

    Missing documentation?¶

    This index only links public documentation that loads without an account. Some vendors (DriveNets, Arrcus, ZTE, and Huawei's configuration guides) keep their SRv6 documentation behind a customer login. If you find a public SRv6 guide that is missing, or a link that broke after a new release, open an issue or pull request on GitHub.
